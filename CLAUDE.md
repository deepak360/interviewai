# InterviewAI — CLAUDE.md
> Read this at the start of every session. Keep it accurate and concise.

## What this project is
A full-stack AI-powered mock interview platform. Users paste a JD + Resume,
get a personalised Q&A bank generated by Claude, study it in flashcard mode,
take a proctored mock interview (camera + mic), and receive a scored debrief
with improvement coaching.

## Tech Stack
| Layer      | Choice                  | Why                                      |
|------------|-------------------------|------------------------------------------|
| Frontend   | Next.js 14 (App Router) | SSR + file-based routing, best DX        |
| Styling    | Tailwind + shadcn/ui    | Utility-first + accessible components   |
| State      | Zustand + React Query   | Minimal boilerplate                      |
| Auth       | NextAuth.js             | OAuth + session management               |
| Backend    | Express + TypeScript    | Simple, explicit, easy to test           |
| ORM        | Prisma                  | Type-safe DB access, great migrations    |
| Database   | PostgreSQL               | Relational + JSONB for AI outputs        |
| Queue      | BullMQ + Redis          | Async Claude scoring jobs                |
| AI         | Claude claude-sonnet-4-6       | Via SDK, prompts version-controlled      |
| Storage    | GCS                     | Interview recordings                     |
| Deploy     | Vercel + Cloud Run      | GCP-native, familiar                     |

## Coding Conventions
- All API responses return `{ data, error }` shape. Never return raw objects.
- Errors: throw `new AppError(message, statusCode)`. Never throw raw strings.
- All DB queries go through `apps/api/src/lib/db.ts`. Never use Prisma client directly in routes.
- Services handle business logic. Routes only parse input, call service, return response.
- All Claude API calls go through `apps/api/src/lib/claude.ts`. Never call Anthropic SDK directly.
- Prompts loaded from `/docs/prompts/` by version key. Never hardcode prompts in code.
- All API inputs validated with Zod schemas before processing.
- TypeScript strict mode everywhere. No `any`.

## Auth Rules
- Access token: JWT, 15 min TTL, in Authorization header
- Refresh token: opaque UUID, 7 days, httpOnly cookie, rotated on every use
- Admin routes: check `req.user.role === 'ADMIN'` via `requireAdmin` middleware
- Never trust client-side role — always verify server-side

## Environment Variables
- Server-only vars: no prefix
- Client-accessible vars: `NEXT_PUBLIC_` prefix
- Never commit .env files. Use .env.example for documentation.

## Running Locally
```bash
# Install all
pnpm install

# Start DB and Redis
docker-compose up -d

# Run migrations
pnpm --filter api prisma migrate dev

# Start both apps
pnpm dev
```
