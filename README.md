# InterviewAI

AI-powered mock interview preparation and simulation platform.

## What it does
- Paste a JD + Resume → get a personalised Q&A bank generated by Claude
- Study the bank with spaced repetition flashcards
- Take a proctored mock interview (camera + mic + live transcription)
- Get a scored debrief with per-answer feedback and improvement coaching

## Tech Stack
Next.js 14 · Express · PostgreSQL · Prisma · BullMQ · Claude API · Tailwind · shadcn/ui

## Project Structure
```
apps/web/          Next.js frontend
apps/api/          Express backend
packages/shared/   Shared TypeScript types
docs/              Planning, specs, rules, prompts, skills
```
